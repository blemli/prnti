# Prnti Anleitung

## Kurz drücken (<1 sek)                                                                                        

Aktuellster Wintibrief wird gedruckt.                                                                                                                                                                              

## Lang drücken (>4 sek)                                                                                        

Alle Wintibriefe werden gedruckt, vom ältesten zum neusten.                                                

Kurz drücken zum Abbrechen.                                                                                  

## Mittel-lang drücken (1–2 sek)                                                                                

Wintibrief nach Nummer auswählen
Nummer wird Ziffer für Ziffer eingegeben:                                                                    

    1. Kurz tippen × Ziffernwert,
        dann mittel-lang drücken → Ziffer bestätigen                                   
    2. Nach bestätigung der 3. Ziffer wird gedruckt                                                                                                          

### Beispiel für #103:                                                                                           

mittel-lang → 1× kurz, mittel-lang → mittel-lang → 3× kurz, mittel-lang
